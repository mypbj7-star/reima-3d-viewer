# REIMA STUDIO 3D 제품 보기

라이마 스튜디오가 만든 360° 3D 제품 모델을 보여 주는 공개 페이지입니다. 이 저장소에는 보기 페이지(index.html)만 있으며 비밀 정보는 없습니다.

사용: `https://mypbj7-star.github.io/reima-3d-viewer/?m=<3D 파일 주소>&o=<방향>&f=1`

- m: 라이마 스튜디오 저장소의 3D 파일(GLB) 주소만 허용
- o: 정면 방향 보정 각도
- f=1: 앞쪽만 돌려 보기
- t: 제목(선택), bg: 배경색(선택), ar=0: 내 방에 놓아 보기 끄기
